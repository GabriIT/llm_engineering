# Troubleshooting FAQ CSV Generation

## Validation error: input directory
Cause:
1. `--input-dir` does not exist.
2. Input path is not a directory.
3. Directory has no `.md` files.

Fix:
1. Point to `myRAG_app/markdown_knowledge` or `/tmp/myrag_markdown_from_skill`.
2. Verify files with:
```bash
ls -la /home/gabri/udemy/llm_engineering/myRAG_app/markdown_knowledge
```

## Validation error: no source sections found
Cause:
1. Markdown files do not contain `## Source: ...` headings.

Fix:
1. Regenerate markdown via `folder-markdown-exporter`.
2. Confirm source sections exist in each markdown file.

## OpenAI/Auth/Network failures
Cause:
1. Missing/invalid `OPENAI_API_KEY`.
2. Model access or connectivity issue.

Fix:
1. Verify `.env` key is set and valid.
2. Run a small local query check from your existing vector tooling.
3. Retry with reduced `--min-rows` for diagnostics.

## Row shortfall below min_rows
Cause:
1. Low-yield content or strong dedupe filtering.
2. Too many near-duplicate questions generated by the model.

Fix:
1. Increase `--max-rows` (headroom before trim).
2. Increase `--max-retries`.
3. Use non-strict mode first, inspect report warnings and low-yield sources.

## CSV quality concerns
Fix:
1. Spot-check random rows for hallucinations.
2. Filter rows by source to inspect problematic markdown files.
3. Re-run generation with adjusted model/temperature if needed.
4. For model-training data, run with `--generation-mode classification` to force category-oriented answers.
